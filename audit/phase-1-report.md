Space, on a 4px baseline: 0, 4, 12, 20, 32, 80, 136, 156px. Breakpoints: 640, 768, 1024px. Grids: 16 columns with 24px gutters and 1240px maximum on desktop; 16 columns with 20px gutters on mobile; a full-bleed grid to 1800px; a 12-column grid to 2100px.

Problems:
1. xl type has 52px leading on 80px type below 768px, so wrapped lines overlap.
2. md2 is smaller than md but named after it.
3. `$icon-sm` uses breakpoint keys sm, md and lg. The breakpoints are s, m and l, so a size change there would apply nowhere.
4. 16 raw hex values in component Sass, 11 of them off the palette. Most are in the internal dashboard. Outside it: #474A45 (contact button), #f5ea8b (`_base.scss` highlight), #db5038 (gardenolator).
5. `var(--font-sans)` is used in the order block and never defined.

## Contrast

Full matrix: `npm run contrast`. Pairs in use that fail WCAG 2.2 AA:

| Where | Text on background | Ratio | Needed |
|---|---|---|---|
| Wordmark, home hero | gold.X on neutral.X | 1.79 | 3 (large text) |
| Red service card | neutral.X on red.X | 3.37 | 4.5 |
| Gold service card | neutral.X on gold.XX | 4.09 | 4.5 |

The card hover states mix in more cream, which lowers these further. Body text (neutral.XXX on neutral.X, 15.13) and purple headings on pale green (purple.XX on green.X, 6.69) pass. The About page photo’s alt text does not describe the photo.

## Visual identity, as built

- Cream page (neutral.X), pale green sections (green.X), dark footer and contact (green.XXX).
- Alegreya Sans throughout, large display sizes, title-case headings in purple.XX.
- Wordmark as live text, bold, in gold.X.
- Photographs with animated spot illustrations laid over them. Spots also mark list items.
- Bright green (green.XX) buttons on dark backgrounds.
- Branding Ref headings: fun, color and illustration; English craft; garden-specific; layout; hippie modernism; hand drawn.

## Creative calls

Each is an open entry in `brand/decisions.md`. The recommendation is a starting point, not a decision.

| ID | Call | Recommendation |
|---|---|---|
| O-05 | Typeface | Alegreya Sans alone. It is what the site is built on, and it is free in Figma, print and social. |
| O-07 | Wordmark | A text wordmark in Alegreya Sans bold, in a color that passes contrast, exported as outlines for print and social. A drawn monogram can follow later. |
| O-08 | Palette roles and names | Two tiers: plain scale names for the values (green-100 to green-900) and role names on top (surface, text, action, accent). |
| O-09 | Accent pairs | Darken red.X and gold.XX until cream text passes 4.5:1, keeping the hues. |
| O-10 | Voice in promotion | The flat voice everywhere. No emoji. No exclamation marks. An event headline is the event’s name. |
| O-11 | Names, places, dates | ‘Grow Good Gardens’ first, ‘Grow Good’ after. ‘Upper Midwest’. ‘Saturday, May 16, 10:00am–noon’. |
| O-12 | Audiences | Leah writes one line per audience. No recommendation on the list itself. |
| O-13 | Art direction | Keep the spot illustrations as the illustration system. Pick one or two Branding Ref headings for the print and social templates. |
